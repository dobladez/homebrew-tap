# dobladez's Homebrew tap

```sh
brew install dobladez/tap/<formula>
brew upgrade <formula>      # when a new version is out
```

| Formula | What it is |
|---|---|
| `clv` | [clview](https://github.com/dobladez/clview): PDFs, images, documents, spreadsheets and archives, shown in the terminal |

Each formula is written by its own project's release workflow, so a change to one belongs in that
project.
